1.d) Componentes, hardware y software, de que consta el sistema informático a que se refiere esta declaración responsable, junto con una breve descripción de lo que hace dicho sistema informático y de sus principales funcionalidades:

Se trata de una API en la nube que genera para sus usuarios (sistemas informáticos de facturación, SIF) registros de facturación y los remite a la Agencia Estatal de Administración Tributaria (AEAT).

En concreto:

  • La API recibe peticiones en formato JSON con los datos relativos a cada operación de facturación de los Obligados Tributarios que se producen en el sistema cliente.
  • Oak Soft VeriFactu API genera el registro de facturación (registro de alta o de anulación) conforme a los esquemas XSD publicados por la AEAT, calcula la huella («hash» SHA-256) encadenada por emisor y devuelve de manera síncrona al SIF cliente el código QR de validación previsto por la normativa.
  • Oak Soft VeriFactu API remite el registro de facturación a la AEAT en los segundos siguientes mediante los servicios web de la sede electrónica, autenticándose con certificado electrónico cualificado, y respetando el control de flujo indicado por la AEAT.
  • Oak Soft VeriFactu API ofrece al cliente SIF mecanismos para consultar el estado de los envíos y acceder al XML de respuesta de la AEAT.
  • Se proporciona asimismo un módulo conector para Odoo que integra la facturación estándar de Odoo (account.move) con esta API.

El componente informático denominado Oak Soft VeriFactu API, en la versión indicada, cumple con los requisitos establecidos en la Ley 58/2003, General Tributaria, el Real Decreto 1007/2023 y la Orden HAC/1177/2024, incluyendo:

- La integridad, conservación, accesibilidad, legibilidad, trazabilidad e inalterabilidad de los registros de facturación generados por los sistemas informáticos de facturación a los que se integra, mediante el encadenamiento de huellas SHA-256 por emisor y la conservación de los XML de petición y respuesta intercambiados con la AEAT.

- El cumplimiento de las especificaciones técnicas y funcionales previstas para la remisión de registros de facturación a la Agencia Estatal de Administración Tributaria cuando se utilice como sistema VERI*FACTU, validado frente a los esquemas XSD publicados por la AEAT y verificado en el entorno de preproducción de la sede electrónica.

Oak Soft VeriFactu API no constituye un sistema de facturación autónomo, sino que actúa como componente integrado en los sistemas informáticos de facturación de los CLIENTES, quienes conservan la responsabilidad del cumplimiento normativo global del sistema informático.

Oak Soft VeriFactu API permite, cuando así se configure por parte del cliente, la generación de los registros de facturación estandarizados y su remisión a través de la interfaz API proporcionada para su envío a la AEAT.
